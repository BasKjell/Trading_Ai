# changelog.d

Je Aufgabe eine Datei `T-xxx.md` mit Datum, Anlass/Ziel, Änderungen, Tests, ausgeführten Prüfungen und
Einschränkungen (Format wie `CHANGELOG.md`). Einzel-PRs ändern `CHANGELOG.md` und `docs/STATUS.md` nicht.
Ein täglicher Sammel-PR übernimmt die Notizen gemergter PRs in `CHANGELOG.md`, löscht die Dateien und
aktualisiert `docs/STATUS.md` (AGENTS.md §2a).
