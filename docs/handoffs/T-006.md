## Bedienung
```bash
python3 -m localtrader run --mode shadow --feed SPY=data/paper/SPY_15m.csv \
  --trade-from 2026-11-20T14:30:00+00:00 --strategies intraday_trend
python3 -m localtrader run --mode paper ... --once        # ein Tick
python3 -m localtrader run --mode paper ... --halt "Grund" # Stopp setzen
python3 -m localtrader run --mode paper ... --resume Name  # Stopp aufheben
python3 -m localtrader run --mode live                     # zeigt nur die Sperrgründe, Exit-Code 2
```
- **Feed:** Der Feed ist eine CSV-Datei wie die Forschungsdateien (`timestamp,open,high,low,close,volume`, UTC). Er enthält nur Bars ab 2026-11-01 und wird fortlaufend ergänzt.
- **Tick:** Den Tick kurz nach jedem Bar-Ende ausführen. Bars, die vor `--trade-from` gesehen wurden, sind nur Warm-up. Für den Trendfilter sind etwa zehn Sitzungen nötig.
- **Zustand:** Er liegt in `state/runtime-<modus>/runtime.sqlite`, mit den Tabellen Bars, Signale, Fills und Audit. Ein Verzeichnis gehört genau einer Kombination aus Modus, Config, Strategien und Start.

## Entscheidungen
- **Wiedergabe statt einer zweiten Engine:** Die Engine ist deterministisch und kausal. Deshalb trifft der Paper-Dienst bei gleichen Bars und Ankunftszeiten dieselben Entscheidungen wie der Backtest. Der Aufwand pro Tick wächst linear mit der Historie. Für einige Monate 15-Minuten-Bars ist das unkritisch.
- **Veraltete Daten:** Während eines veralteten Ticks wird nichts gebucht. Eine Order, die vorher aus frischen Daten entstanden ist, wird beim nächsten zulässigen Open ausgeführt, so wie sie beim Broker liegen würde. Verspätete Bars werden erst ab ihrer Ankunft zu Information.
- **Feed-Verzögerung (ADR 0006):** Bars werden erst 15 Minuten nach ihrem Ende gelesen. Eine Bar gilt ab 35 Minuten Alter als veraltet. Erwartet wird eine Bar erst, wenn die Sitzung zum Zeitpunkt `jetzt − 35 min` lief. Der Paper-Betrieb entspricht damit dem Szenario `delay1`.
- **Holdout:** Bars vor dem Ende des zentralen Holdout-Fensters (Protokoll `central.end_exclusive`) werden abgelehnt, bevor ein Preis geparst wird. Ein Test vergleicht die Konstante mit dem Protokoll.
